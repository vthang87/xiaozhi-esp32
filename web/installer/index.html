Web Serial is not available here. Open this page in Chrome or Edge on a desktop computer.

Checking hosted firmware…

  1. 1
    Plug the ES3C28P into USB. Use the native USB-C port, not a UART dongle, for the first flash.
  2. 2
    Hold BOOT if the serial port does not appear, then click Connect and install and pick the device.
  3. 3
    Allow erase on first install so the 16 MB partition table (including the theme slot) is written. Press RESET when it finishes.
First install writes a full image. Later you can flash only a theme package at 0xF80000 without replacing the app.
